# EXP002 Metadata

One YAML sidecar per raw data file, same stem. Template in
`experiments/EXP002/MEASUREMENTS.md`.

Must record: experiment ID, date, operator, source revision, parameter-set ID, controller
gains and derivative filter, excitation amplitudes and the predicted `u_peak`, sampling
period, units for every signal, hardware configuration (sign conventions, pendulum
removed/clamped), and execution status.

**Empty — no data exists.**
